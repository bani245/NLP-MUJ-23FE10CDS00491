project title : NLP JOB MATCH & RESUME TAILORING 
project detail:- 
This project is a ** Resume Matching & Skill Gap Analysis Engine** built with classical Natural Language Processing (NLP) techniques. It evaluates candidate resumes against job descriptions deterministically, offline, and in real time without external API calls

Methodology:
1. Text Preprocessing & Normalization
2. Vector Space Embedding(tf-idf vectorization, n-gram support)
3. Similarity Calculation (cosine similarity)
4. Keyword Gap
